# TYPE BURST 検索コンテンツ拡張計画

最終更新: 2026-07-28
対象: 検索流入を月間5,000人へ伸ばすための、コンテンツとキーワードの設計。
前提と運用ルールは `docs/SEO_SAO_HANDOVER.md` に従う。本書はその「何を作るか」を補う。

## 1. 現状の評価

既存13ガイド・6ツールは、本文の質・構造・FAQ・内部リンクのいずれも水準を満たしている。
薄い記事ではないため、書き直しではなく**未対応クラスタの追加**と**2つの弱点の是正**が課題。

### 弱点1: 検索意図とフォーマットの不一致

`free-typing-game.html`（狙い: 「無料タイピングゲーム」）は選び方の基準を説明する記事だが、
このクエリの検索者が求めているのはサービスの一覧である。上位はすべてまとめ記事。
記事の品質を上げても意図が違うため順位は上がらない。

対処方針:
- 頭のクエリ（「無料タイピングゲーム」単体）は当面狙わない。
- 記事の狙いを、意図が一致する長尾（「タイピングゲーム 選び方」「タイピング練習 続かない」）へ寄せる。
- 競合サービスを列挙する比較記事は作らない。他社の紹介で稼ぐより、自社ツールで解決する方が資産になる。

### 弱点2: 一次データが存在しない

競合を含め、日本語タイピングの解説記事はほぼ全てが出典のない数値を書いている。
TYPE BURST は打鍵データ（苦手キー、指別の遅れ、ミス率）を実際に持つ唯一の側にいる。

これを匿名集計して公開することが、被リンクとAI引用の両方に対して
記事を何十本書くよりも効果が大きい。詳細は §4。

## 2. 未対応キーワードクラスタ

既存記事が触れていない、かつ検索が発生している意図。優先度順。

| # | クラスタ | 代表クエリ | 競合 | 備考 |
| --- | --- | --- | --- | --- |
| 1 | **ローマ字の個別の打ち方** | 「ん」の打ち方 / 小さいつ 打ち方 / を 打ち方 / ゃゅょ 入力 | 薄い | typing-engine の対応表がそのまま根拠になる。最優先 |

### クラスタ1を最優先にする理由

「ん」「っ」「を」「ゃゅょ」の打ち方は、
- 実際に検索されている具体的な疑問である
- 競合が「ローマ字表」の画像1枚で済ませており、答え切っていない
- **TYPE BURST は全異表記を保持したエンジンを持つため、網羅性と正確性で誰にも負けない**
- `/tools/romaji-table.html` へ自然に送れる

これは他社が模倣できない構造的優位であり、最初に取るべき陣地。

### 除外するもの

- キーボード・機材の選び方（アフィリエイト競合が厚く、本サービスの役に立たない）
- 競合サービスの比較・ランキング記事
- 都市名・学校名・職業名を差し替えただけの量産記事

## 3. 新規ツール（3本）

記事より順位が付きやすく、自然リンクを集めやすいため、記事と並行して優先する。

| ツール | 狙うクラスタ | 独自価値 |
| --- | --- | --- |
| 数字・記号タイピング練習 | 3 | 数字列・記号のみを反復できる場が存在しない |
| かな入力／ローマ字入力 判定 | 2 | どちらが向くかを入力実測で判定する |
| タイピング検定レベル判定 | 5 | 実力測定モードの受け皿。仕事で通用するかに答える |

3本目は、ゲーム本体の「実力測定モード」（別途計画）と接続することを前提に設計する。
SEOと機能開発が同じ方向を向く数少ない接点であり、切り離して作らないこと。

## 4. 一次データの公開（最重要）

### 何を出すか

匿名集計した打鍵統計。例:
- ミス率の高いキーの順位
- 指別の平均遅延
- 難易度別の平均KPM・正確率の分布

### なぜ効くか

- 競合が模倣できない。データを持っていないため
- 報道・ブログが引用する動機になる。＝被リンクが自然に集まる
- AI検索が引用しやすい。数値と出典と手法が明確なため
- 「タイピング 平均」系クエリに、唯一の根拠つきで答えられる

### 満たすべき条件

1. **個人を特定できる形にしない。** 集計値のみを出し、生ログは出さない。
2. **サンプル数と集計期間と手法を必ず明記する。** これを欠くと信頼性がゼロになる。
3. **プライバシーポリシーとの整合を取る。** 統計利用の記載が必要かを確認する。
4. **母集団の偏りを正直に書く。** 本サービスの利用者は日本語ローマ字入力のPC利用者に偏っている。
   「日本人の平均」と書いてはならない。「TYPE BURST 利用者の集計」と書く。

この4番目を守れないなら公開しない。誇張した瞬間に、他の全記事の信頼も失う。

## 5. 被リンク獲得

コンテンツ以上に順位を左右する。オンサイトが完成している以上、ここが最大の制約。

| 経路 | 手段 | 費用 |
| --- | --- | --- |
| 技術記事 → はてなブックマーク | 日本語ローマ字入力の受理グラフ、決定論エンジンの設計 | 0円 |
| メディア掲載 | 窓の杜・GIGAZINE・ねとらぼ・もぐらゲームス等への直接売り込み | 0円 |
| 教育機関ドメイン | 学校・自治体の教材リンク集。登録不要・個人情報を取らない点が条件を満たす | 0円 |
| 一次データの引用 | §4 の統計公開 | 0円 |

リンク購入、相互リンク、被リンクサービスは使わない。

## 6. 進め方

1. 技術記事を公開し、被リンクの起点を作る
2. 新規ツール3本
3. クラスタ1（ローマ字の個別の打ち方）
4. Search Console の実データを見て、クラスタ2〜6の順序を確定する
5. データが溜まった段階で §4 の一次データを公開する

新規ページは `docs/SEO_SAO_HANDOVER.md` §3 のチェックリストを必ず通す。
