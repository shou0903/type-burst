プライバシーポリシー

最終更新日: 2026年8月5日

TYPE BURST(以下「本サービス」といいます)における、利用者の情報の取り扱いについて説明します。

1. 収集する情報

本サービスは会員登録を必要とせず、主に以下の情報をご利用のブラウザ内(localStorageまたはsessionStorage)に保存します。

  • 効果音・演出・アクセシビリティ等の設定
  • 直近60試合分のスコア・KPM・正確率などのプレイ記録
  • CPU対戦の勝敗記録
  • デイリーチャレンジの挑戦回数、連続日数、連続記録保護、カレンダー
  • ランキング登録用に入力したニックネーム
  • ランキングと記録引き継ぎに使用する、個人情報を含まない匿名のプレイヤーID
  • 記事やツールからゲームを開始した経路（同じタブのsessionStorageに一時保存）

音量・表示・演出などの端末設定はお使いのブラウザ内にのみ保存され、ブラウザのデータを削除すると消去されます。プレイ記録のサーバー保存については、本ポリシーの「8. 匿名プレイ記録の保存と引き継ぎ」をご確認ください。

また、アクセス状況と表示性能の把握のため、Vercel Web AnalyticsおよびVercel Speed Insightsにより 閲覧ページ・参照元・国・デバイス種別・Core Web Vitals等の匿名の集計情報を取得しています (詳細は下記「3. 広告について」参照)。

ランキング機能をご利用いただく場合のみ、入力したニックネーム、匿名のプレイヤーIDと、通常サバイバルでは スコア・最大連鎖・生存時間・レベル、デイリーチャレンジではスコア・KPM・正確率・最大連鎖・生存時間を 本サービスのサーバー(Vercel上のサーバーレス関数、データ保存にはRedisを利用)へ送信し、ランキング表示と本人順位の計算のために保存します。公開するランキングレスポンスに匿名のプレイヤーIDは含めません。ランキングへの登録は任意であり、 ニックネームを入力しない限り送信されません。本名・メールアドレスなど、個人を特定できる情報は ニックネームに入力しないでください。

デイリーランキング記録は45日間保存します。通常ランキングは難易度ごとに上位500件を保持し、圏外になった記録は削除します。 ランキング記録の削除を希望する場合は、対象のニックネーム、難易度または挑戦日を添えてお問い合わせ窓口へご連絡ください。

ランキング送信、記録の復元などのAPIでは、不正利用や総当たり攻撃を防ぐため、接続元IPアドレスに基づく試行回数カウンターを最長1時間保存する場合があります。 また、ホスティング事業者が通信の配信・セキュリティ確保のためIPアドレス等を処理する場合があります。

2. Cookieの使用について

本サービス自体はログイン等の目的でCookieを使用していません(上記の保存はlocalStorageのみ)。 ただし、Google AdSenseによる広告配信では、広告の配信・測定・不正防止・表示の最適化等の目的で、 GoogleまたはそのパートナーがCookieその他の識別技術を使用することがあります。

3. 広告について

本サービスは、十分な画面幅がある場合のホーム画面左右、および解説・練習ツール等のページにGoogle AdSenseによる広告を 表示することがあります。広告の内容、配信の有無および使用されるデータは、利用地域、端末、 Google側の広告配信設定、広告在庫等によって異なります。

欧州経済領域(EEA)、英国およびスイスなど、同意の取得が必要な地域では、Googleの認定同意管理 プラットフォーム(CMP)を通じて、広告に関する選択肢を表示します。利用者は表示されるメッセージから、 同意、不同意または詳細設定を選択できます。選択内容に応じて、パーソナライズ広告または 制限付き広告が配信されるか、広告が配信されない場合があります。

Googleによる広告Cookieの使用については Google広告ポリシーをご覧ください。パーソナライズ広告の無効化は Google広告設定 から行えます。

Googleが広告配信などで取得した情報をどのように使用するかは、 Googleのサービスを使用するサイトやアプリから収集した情報のGoogleによる使用をご確認ください。広告配信に伴い、第三者がブラウザへCookieを保存したり、ウェブビーコン、IPアドレスその他の識別子を使用したりする場合があります。

本サービスはVercel Web AnalyticsおよびVercel Speed Insightsを利用し、アクセス状況 (ページビュー・参照元・国・デバイス種別など)と表示性能(Core Web Vitalsなど)を集計しています。 Cookieを使用せず、個人を特定できる情報(氏名・メールアドレス・IPアドレスそのもの等)は 収集・保存されません。あくまで「どのページが・どの程度見られているか」「実際の端末で快適に表示できているか」を 把握するための匿名の集計情報のみです。

ローマ字入力ラボでは、入力したかなやローマ字そのものは送信せず、課題の種類、候補件数、 試打・ドリルの完了など、機能改善に必要な匿名の分類イベントだけを集計します。

4. ゲーム中に入力される内容について

本サービスはタイピング練習を目的としており、ゲーム画面に表示された定型文をローマ字で入力する形式です。 入力されたキー情報は本サービスの動作(ブロックの判定・スコア計算)にのみ使用され、外部へ送信・保存されません。

5. 第三者への提供

本サービスは利用者の情報を第三者へ販売することはありません。ランキング機能を利用した場合の ニックネーム・スコア等はランキング表示のためVercel(ホスティング・データ保存基盤)上に保存されますが、 それ以外の第三者へ販売することはありません。Google AdSenseの広告配信に伴い、Googleおよび広告配信に 関与する事業者がCookie等の情報を取り扱う場合があります(詳細は上記「3. 広告について」参照)。

7. 本ポリシーの変更

本ポリシーの内容は、必要に応じて予告なく変更されることがあります。変更後の内容は本ページに掲載した時点で効力を生じます。

8. 匿名プレイ記録の保存と引き継ぎ

ゲーム終了後、当サイトは結果画面の表示を妨げないバックグラウンド通信により、ブラウザで発行する匿名のプレイヤーIDに紐づけて、ニックネーム、生涯累計、直近のプレイ結果、デイリー連続記録・連続記録保護、CPU対戦戦績をサーバーへ自動保存します。保存に失敗した場合もゲームには影響しません。メールアドレス、パスワード、氏名その他の登録情報は収集しません。

保存の目的は、端末変更やブラウザデータ消去後にプレイ記録を復元できるようにすることです。端末固有の設定（音量、表示、演出設定など）は保存しません。記録は最後の保存から最長1年間保持し、その後削除されます。

ブラウザのデータを削除しても、既にサーバーへ保存された記録は自動では削除されません。ゲーム内の設定画面にある「クラウドに保存した記録を削除」から、保存済みの記録と引き継ぎコードを削除できます。削除後、同じコードでの復元はできません。
