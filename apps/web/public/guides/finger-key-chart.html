Shiftを使う記号（! " # など）は数字・記号のタイピング練習の記号入力表で網羅しています。あわせて確認してください。

指ごとの負担は同じではない

人差し指と中指は担当キーが多く、日本語ローマ字入力でも使用頻度が高くなりがちです。一方で小指は担当キーが少ないぶん、1つのキーに集中して負担がかかります。Aや;で小指がすぐ疲れる場合、それは力の入れすぎであることが多く、軽く触れる程度の力で十分反応します。

表と違う指を使ってよい場面

この表は基準であり、絶対のルールではありません。次の場合は、表からズレていても直す優先度は低いと考えてよいでしょう。

  • すでにミスなく安定した速度で打てている
  • 手が小さい・大きいなど、体格の都合で表どおりだと窮屈
  • 使っているキーボードの形状（分割型・コンパクト型など）が標準的なJIS配列と異なる

直す価値があるのは、特定のキーで毎回止まるか、ミスが集中している場合です。苦手キー練習で該当のキーを含む語を反復すると、担当指を含めて見直すきっかけになります。

JIS配列・US配列・ノートPCで確認すること

早見表を見ても手元と一致しないとき、まずキーボードの配列を確認します。JIS配列では「;」「:」「@」などが右側に並びますが、US配列では記号の位置やShiftとの組み合わせが異なります。ノートPCや省スペースキーボードでは右側の幅が短いこともあります。配列が違うのに指の担当だけを無理に合わせると、手首をひねる原因になります。

困っている状態最初に確認判断
アルファベットは安定している記号だけ位置が違うJIS/USの違いを調べ、記号だけ別練習
右端のキーで手が窮屈キーボード幅と手の位置手首を横へ折らず、短時間で区切る
特定の指だけ疲れる担当キーを別の指で代用していないか担当を固定し、力を抜いて再測定
表どおりだとミスが増える実際の配列と入力方式安定する指を採用し、記録に残す

早見表を覚えたかではなく、再現できるかを測る

担当指を暗記した直後に長文へ進むと、指が戻る前に次のキーへ移る癖が残ります。次の5分テストでは、速さではなく「同じ指で同じ動きができるか」を確認します。

  1. 1分：ホーム段を左右別々に入力し、手首を動かさない。
  2. 2分：苦手な列を縦に3キーずつ打つ（例：QAZ、WSX、EDC）。
  3. 1分：数字または記号を5種類だけ入力する。
  4. 1分：短文へ戻り、ミスしたキーと使った指をメモする。

担当指を短語へ移すチェック

表を見ながら単独キーを押せても、文章では隣のキーへ急いで指が流れます。短語を使い、目的のキーを打った直後にホーム段へ戻れるかを確認します。戻れない場合は、指を強く押し込むのではなく、手を一度浮かせて置き直します。

確認する組み合わせ意識する動き合格の目安
fr・ju上段へ伸ばして同じ指を戻す10回中9回、手元を見ずに通る
sw・ol隣の指を同時に動かさない音のリズムが一定になる
qa・p;小指だけを伸ばし手首を横へ折らない痛みや肩の力みが出ない

数字・記号を実務へ移す

アルファベットの担当が安定しても、数字や記号はShiftを伴うため手の位置が崩れやすくなります。最初から長いパスワードやコードを練習せず、数字2つと記号1つを含む短い文字列を使います。JIS配列とUS配列では位置が変わるため、下の例は「キーの位置」ではなく、使う手と姿勢を確認するための素材です。

課題最初の1分崩れたとき
数字だけ123・789を交互に入力指をホーム段へ戻してから再開
Shiftを含む記号1種類だけ選び、左右のShiftを固定手首をひねらず休憩する
メールやURL短い文字列を3回、速度を測らず入力記号部分だけを切り出す

よくある質問

数字キーはどの指で打ちますか？

アルファベットの上段とほぼ同じ担当です。1と2は左小指、3は左薬指、4と5は左中指と左人差し指、6と7は右人差し指、8は右中指、9は右薬指、0は右小指が基本の担当です。ただし数字はテンキーで打つ人も多く、その場合は配列自体が異なります。

表と違う指を使っていますが、直すべきですか？

すでに安定した速度で打てているなら、無理に直す必要はありません。表はあくまで基準であり、手の大きさやキーボードの形状によって最適な指が変わることもあります。直す価値があるのは、特定のキーで毎回止まる、ミスが多いなど、実際に困っている場合です。

記号キーの位置がキーボードによって違うのはなぜですか？

日本語配列（JIS）と英語配列（US）で記号の位置が異なるためです。特にアットマークやダブルクォート、アンダースコアの位置が違います。この早見表はJIS配列を基準にしています。

指ごとに担当するキーの数が違うのはなぜですか？

指の可動域と、キーボードの列数の兼ね合いです。人差し指は上下左右に動かしやすいため、中央寄りの複数列を担当しています。小指は動かしにくいため、端の列を1つずつ担当する配置になっています。

覚えるより、体で確かめる

表を眺めるだけでは指は覚えません。TYPE BURSTの初級モードで、実際に手を動かしながら定着させましょう。
