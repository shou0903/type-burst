# TYPE BURST AdSense設定

最終更新: 2026-07-29

## サイト側の構成

- `ca-pub-5471900652537950` のAdSenseアカウントメタタグと公式スクリプトを、広告対象ページの`head`へ静的に配置する。
- ゲーム本体 (`https://type-burst.com/`) は既存の左右手動広告だけを使用する。
- ゲームの手動広告は画面幅1450px以上で表示し、ゲーム盤面と重ならないようにする。
- ゲーム紹介、練習ガイド、無料ツールではAdSenseの自動広告を利用できる。
- 利用規約、プライバシーポリシー、編集方針、プレス素材ページには広告コードを置かない。
- `ads.txt` は `https://type-burst.com/ads.txt` で配信する。
- 独自の広告同意バナーは使用せず、地域別の同意取得はGoogle認定CMPで管理する。

## 本番公開前にAdSenseで行うこと

### 1. Google CMPを公開する

1. AdSenseの「プライバシーとメッセージ」を開く。
2. 「欧州の規制」を開く。
3. `type-burst.com`を対象にメッセージを作成する。
4. 利用者の選択肢は「同意する・同意しない・オプションを管理」の3ボタン構成にする。
5. プライバシーポリシーURLに `https://type-burst.com/privacy.html` を設定する。
6. メッセージを公開する。

### 2. 自動広告からゲーム本体を除外する

1. AdSenseの「広告」から`type-burst.com`の編集画面を開く。
2. 「除外ページ」から除外を追加する。
3. URLへ `https://type-burst.com/` を入力する。クエリや`#play`は付けない。
4. 「このページのみ」を選択する。

ゲーム本体にはコードで設置した左右の手動広告があるため、自動広告は重ねない。

### 3. 自動広告を控えめに設定する

- 自動広告: オン
- インテント重視のフォーマット: オフ
- オーバーレイフォーマット:
  - アンカー広告: オフ
  - 全画面広告: オフ
  - サイドレール広告: オフ
- ページ内フォーマット:
  - バナー広告: オン
  - Multiplex広告: オン
  - 関連検索: 最初はオフ
- 広告数: 最少寄りから開始
- 広告間の最小距離: 広めから開始
- 既存の広告を最適化: オフ

設定後に「サイトに適用」を押す。反映には時間差があるため、直後に広告が表示されなくても設定を連打しない。

## 公開後の確認

1. `https://type-burst.com/` のHTMLソースに `google-adsense-account` と `adsbygoogle.js` がある。
2. `https://type-burst.com/ads.txt` がHTTP 200で表示される。
3. AdSenseの「サイト」で`type-burst.com`が「準備完了」になっている。
4. ポリシーセンターに未解決の問題がない。
5. ゲーム本体に自動広告が出ず、幅1450px以上では左右の手動広告だけが候補になる。
6. ガイド・ツールページのプレビューにページ内広告候補が表示される。

広告在庫、審査状態、利用地域、広告ブロッカーによって広告が空欄になる場合がある。コードが認識されていても、常に広告が表示されるとは限らない。
