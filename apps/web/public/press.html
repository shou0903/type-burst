約100字｜短報用

TYPE BURSTは、打ち終わった言葉ブロックが爆発し、連鎖して消える無料タイピングゲーム。登録不要で、PCブラウザからすぐに遊べる。速さだけでなく、どこを消すかの戦略も楽しめる。

約200字｜標準

TYPE BURST（タイプバースト）は、日本語の言葉をローマ字で入力し、ブロックを爆発させて消していく無料のPCブラウザ向けタイピングゲームです。打ち終わったブロックは消えるだけでなく、落下や特殊ブロックをきっかけに連鎖することがあります。速く正確に打つ力と、次にどこを消せば盤面が動くかを考えるパズル性を組み合わせた、登録不要ですぐ始められるゲームです。

約400字｜詳しい紹介用

TYPE BURST（タイプバースト）は、日本語の単語や短文をローマ字で打ち、画面上のブロックを爆発させて消していく、無料・登録不要のPCブラウザ向けタイピングゲームです。特徴は、正しく打ち終わったブロックが消えるだけで終わらないこと。ブロックが落下して同じ種類がそろうと連鎖し、ボムやプリズム、TYPE BURSTなどの特殊効果を使えば、盤面を一気に動かせます。求められるのは入力の速さだけではありません。どの言葉を先に打つか、どこを消せば大きな連鎖につながるかを考えることで、タイピングとパズルの両方の手応えを楽しめます。サバイバル、CPU対戦、毎日共通の2分間に挑むデイリーチャレンジを用意。プレイ後にはKPM、正確率、キーごとの傾向を振り返れるタイピング分析も表示されます。
