TYPE BURST（タイプバースト）

TYPE BURST（タイプバースト／たいぷばーすと）は、日本語をローマ字で入力してブロックを爆破する、無料のタイピング×連鎖パズルゲームです。

ブロックを消す順番まで考える「つなげるパズルタイピング」だから、タイピングパズルやパズルタイピングを探している人にも、速さと連鎖の両方を楽しめます。

登録やインストールは不要。PCブラウザとキーボードがあれば、初級・中級・上級・神級のサバイバルやCPU対戦をすぐに遊べます。

サバイバル、CPU対戦、2分間のデイリーチャレンジを用意し、プレイ後にはKPM、正確率、最大連鎖、 苦手キーを確認できます。数字を見て次の練習を選べるため、ただスコアを競うだけで終わりません。

遊んだ結果を、次の上達につなげる

TYPE BURSTでは、打ち終えたブロックが爆発し、同じ色がつながるとまとめて消えます。 そのため入力速度だけでなく、どの場所を消せば連鎖が起きるかという判断も必要です。 初心者は正確率を優先し、慣れたら速度と連鎖を同時に狙うことで、自分の段階に合わせて遊べます。

初めての練習

初級で正確率95％以上を目標にし、打ち間違いによる手戻りを減らします。キー位置から始める場合は、順番を飛ばさず短時間ずつ進めます。

初心者向け7ステップ

ミスの原因を確認

KPMだけでなく、正確率と苦手キーを一緒に見ます。特定の文字で止まる場合と、長い文章の後半で崩れる場合では練習方法が違います。

ミスタイプ対策

同じ条件で測定

文章の難しさや測定時間が違えば速度も変わります。同じツールで複数回測り、最高値だけでなく正確率と中央値を比べます。

60秒で速度を測る

迷った日の10分メニュー

  1. 2分：速度測定でKPMと正確率を確認する
  2. 3分：苦手キーまたはローマ字を限定して練習する
  3. 5分：TYPE BURSTをプレイし、正確率を保ったまま連鎖を狙う

結果画面で見る4つの指標

KPM
1分あたりの打鍵数です。測定時間と問題の難しさをそろえて比較します。
正確率
速さの土台です。低下した日は速度を少し落とし、どの文字でミスしたかを確認します。
最大連鎖
盤面を見て消す順番を選べたかの目安であり、入力速度とは別のゲーム攻略指標です。
苦手キー
止まりやすい文字を特定し、すべてを打ち直すのではなく対象だけを短く反復するために使います。
