# TYPE BURST — 日本で最も遊ばれるタイピングゲームへの成長計画

**更新日:** 2026-08-27
**対象市場:** 日本国内・日本語ローマ字入力
**目的:** TYPE BURSTを「練習だから仕方なく打つ」サービスではなく、面白いから毎日遊び、その結果タイピングも上達する日本の定番PCゲームへ育てる。

## 1. 勝ち筋

既存のタイピングゲームと文章量だけで競争しない。TYPE BURSTの核は、打つ速さに加えて「どのブロックを先に消すか」で連鎖と得点が変わることにある。

> 日本語をローマ字で打ち、ブロックを爆破して連鎖を作る、タイピング×連鎖パズル。

国内1位を狙うための成長エンジンは次の4つに限定する。

1. **3秒で面白さが伝わる:** 実際の盤面、爆発、連鎖、入力中ローマ字を最初の画面で見せる。
2. **初回を完走できる:** 7ステップ体験から初級へ接続し、最初の結果まで迷わせない。
3. **毎日戻る理由がある:** 全員共通の2分デイリー、順位、連続記録、週次の成長実感を一つの習慣にする。
4. **記録が次の新規プレイを生む:** X・LINE・URL共有を、画像を見せるだけでなく同じ日の勝負への参加に直結させる。

## 2. 主な国内ユーザー

- **ゲーム目的の中高生・大学生:** 短時間、順位、友人との比較、派手な連鎖を重視。
- **上達目的の学生・社会人:** KPM、正確率、苦手キー、具体的な次の練習を重視。
- **配信者・動画投稿者:** 視聴者と同じ条件で挑める企画、結果が一目で分かる画面を重視。
- **学校・部活・PC教室:** 登録不要、同一条件、短時間で繰り返せることを重視。専用管理機能は需要確認後に作る。

全員に同じ画面を詰め込まず、検索記事・共有リンク・通常訪問という入口ごとに最初の主行動を変える。

## 3. 変えない前提

- 日本語UIと日本語ローマ字入力を主対象にする。英語版・海外SEOは当面作らない。
- 登録不要。メールアドレス・パスワードを要求しない。
- PCと物理キーボードを主対象にする。スマートフォンはPCへの受け渡しに集中する。
- Pay-to-Win、ガチャ、キャラクター収集、ストーリー、外部AI API、BGMは追加しない。
- サバイバルの行上昇速度は全難易度共通とし、難易度差は文章長で作る。
- ゲームコアの決定性、入力方式の多様な受理、難易度別ランキングを維持する。
- 機能数ではなく、開始・完走・再挑戦・翌日再訪・共有経由開始の改善で優先順位を決める。

## 4. 成長ファネル

```text
検索・SNS・友人からの共有
          ↓
入口に合った主CTA（チュートリアル / 指定難易度 / 今日の2分勝負）
          ↓
初回ゲーム完走
          ↓
結果・順位・具体的な次の行動
          ↓
再挑戦 / 分析 / デイリー
          ↓
翌日・翌週の再訪
          ↓
結果共有 → 新しい参加者
```

## 5. 指標

### 北極星指標

**1週間に2日以上、ゲームを完走した匿名プレイヤー数**

ページ閲覧や開始ボタンだけでなく、繰り返し価値を得た人数を重視する。現行のVercelイベント件数だけでは匿名ユニーク人数やD1/D7を厳密に算出できないため、当面は開始・完了・再挑戦・共有経由開始の率を先行指標として使う。イベント件数を「ユーザー数」と呼ばない。

### 主要指標

- 集客: 日本語一般検索クリック、共有ページ閲覧、共有経由のゲーム開始
- 活性化: 初回CTAクリック、チュートリアル完了、初回ゲーム完了
- 継続: 結果からの再挑戦、デイリー完走、週2日以上の完走、D1/D7/D30
- 拡散: 結果共有画面表示、共有リンク作成、共有リンクからのデイリー開始
- 品質: LCP、CLS、INP、JS例外、ゲーム中フレーム安定性、ランキング異常値

### 「国内1位」の判定

競合の実利用者数が公開されない限り、根拠なく1位を名乗らない。四半期ごとに、指名検索、一般検索クリック、外部トラフィック推定、SNS言及、公開ランキング参加数を同じ条件で比較する。内部では月間完走者・総完走数・週2日継続者を伸ばし、第三者データで優位を確認して初めて対外表現を判断する。

## 6. 実行計画

### 0〜30日 — 初回と共有の基準値を作る

1. 初回だけチュートリアルを主CTAにし、完了後は初級へ直結する。旧ユーザーは誤って初回扱いしない。
2. ヒーローの実演盤面を1024px以上でCTAと同時に見せる。
3. 入口・開始・完了・再挑戦・分析・共有を匿名かつ低粒度で計測する。
4. デイリー結果の共有ページから「今日の2分勝負」へ直接参加できるようにする。
5. 公開後7日間はイベント重複・属性数・個人情報の非送信を監査し、その後23日間で最大の離脱点を1つ決める。

### 31〜90日 — 毎週戻る上達ループ

1. 結果画面に「次の1戦で狙う目標」を1つだけ提示し、再挑戦と分析を競合させない。
2. 端末内データから週次サマリーを生成し、プレイ回数・ベストスコア・平均正確率・最大連鎖を一画面で見せる。
3. 同じSeed・同じ条件で友人が遊べる期限付きチャレンジリンクを、デイリーで得た検証結果を基に設計する。
4. デイリー参加者数・次順位までの点差・自己ベストとの差を、結果とホームで一貫して見せる。
5. 検索記事は新規量産より、表示されている日本語クエリのCTR・本文満足度・ゲーム開始率を改善する。

### 91〜180日 — 国内で話題が続く競技化

1. 週末・季節の同一条件イベントを実施する。新通貨や報酬ガチャは作らない。
2. 配信者が視聴者へ渡せるチャレンジURLと、結果を1枚で比較できる表示を用意する。
3. 不正値監視・ランキング失格基準・ルール説明を整え、競技性を訴求できる信頼を作る。
4. 学校・PC教室向けには、登録なしで同じ課題へ参加できるURLを先に検証し、管理画面は需要が確認できた場合だけ作る。

### 181〜365日 — 日本の定番へ

1. 継続率の高い企画だけを年間イベントとして定着させる。
2. 学校、PC教室、メディア、ゲーム配信者との掲載・企画導線を、専用の紹介素材と計測URLで運用する。
3. ブランド検索「TYPE BURST」「タイプバースト」と、一般検索「無料タイピングゲーム」「タイピング練習」の双方から、目的に合う入口へ着地させる。
4. 競合比較は誇張せず、第三者データと実参加数で国内トップ水準を確認する。

## 7. デザイン原則

- **日本のアーケード競技感:** ダークな盤面、4属性、爆発、スコアを主役にし、管理画面風カードを増やしすぎない。
- **1画面1主行動:** 一般初回はチュートリアル、通常はサバイバル、共有流入は今日の2分勝負、結果は次の一戦。
- **スクショで意味が通る:** ブランド、モード、難易度、スコア、順位、主要指標を1画面に収める。
- **小さくしすぎない:** ノートPCで補助ラベルも読める11〜12px以上を基準にする。
- **色だけに依存しない:** DANGER、成功、難易度、順位状態は文字・形・音を併用する。
- **演出で情報を隠さない:** ポップアップを盤面内に収め、reduced-motionでは同じ意味を静的に伝える。

## 8. リリース判断

- typecheck、全テスト、本番ビルドが通る
- 対象画面を1024×768と1280×720で実ブラウザ確認する
- 深いリンク、戻る、キーボード、reduced-motion、通信失敗時の劣化を確認する
- スコア計算・ランキング送信の回帰がない
- L7 QAとL11独立レビューのBlocker/Highが残っていない
- 本番反映は別途明示的に判断する

## 9. 現在の実装スライス

初回定着ループとヒーロー品質はローカル実装・検証済み。次のR2スライスとして、デイリー結果の共有リンクに許可済み遷移先を保存し、共有ページとホームの主CTAを「今日の2分勝負」へ接続する。任意URLは保存せず、既存共有リンクは従来どおりホームへ戻す。
