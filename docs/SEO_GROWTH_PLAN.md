# TYPE BURST SEO成長計画

最終更新: 2026-07-29

## 目標

- 検索流入: 月間5,000ユーザー
- 補助指標: 検索クリック、表示回数、CTR、平均掲載順位、検索流入後のゲーム開始数
- 対象: 日本語のタイピングゲーム・タイピング練習・速度測定に関する検索

順位や流入数は検索エンジンが決めるため保証できない。短期間の記事量産ではなく、検索者の課題をページ内で解決し、そのまま測定・練習・ゲームへ進める構造を作る。

## 検索流入の4本柱

### 1. ブランド

- TYPE BURST
- Type Burst
- タイプバースト
- たいぷばーすと

トップページとゲーム紹介ページで正式名称・読み方・特徴を一貫させる。表記ゆれごとの薄いページは作らない。

### 2. 初心者の悩み

- タイピング 初心者
- タイピング 何から
- ローマ字 タイピング 練習
- ホームポジション
- ブラインドタッチ 練習

`/guides/typing-beginner.html` を親ページとし、症状に応じて既存の専門記事へ送る。

### 3. 測定・改善

- タイピング 速度測定
- KPM WPM
- タイピング 正確率
- タイピング ミス 多い
- 苦手キー 練習

解説だけで終わらせず、無料ツールで測定・反復できる状態を維持する。

### 4. ゲーム・継続

- タイピングゲーム 無料
- タイピング練習 無料
- タイピングを速くする方法

「無料・登録不要」だけでなく、連鎖パズル、結果分析、デイリー、ランキングというTYPE BURST固有の体験を示す。

## 新規ページを作る条件

次の条件をすべて満たす場合だけ追加する。

1. 既存ページとは異なる検索者の目的がある。
2. 読者が検索し直さず、次の行動まで決められる。
3. TYPE BURSTの実装経験、測定ツール、診断表、練習表など独自の価値を含む。
4. 親ページと2本以上の関連ページから内部リンクできる。
5. 誇張、根拠のない平均値、架空の体験談、競合への誹謗を含まない。

似たキーワードごとにページを量産しない。意図が同じ場合は既存記事を改善する。

## Search Consoleの週次運用

毎週同じ曜日に、過去28日とその前の28日を比較する。

### クエリ単位

- 表示回数が増えているクエリを確認する。
- 掲載順位4〜15位でCTRが低いクエリは、title・導入・meta descriptionが検索意図と一致しているか見直す。
- 掲載順位8〜20位のクエリは、上位ページにあって自ページにない疑問を調べ、必要な内容だけ追加する。
- 同じクエリに複数URLが表示される場合は、意図の重複を確認して統合または役割分担する。

### ページ単位

- 表示回数、クリック、CTR、平均掲載順位を記録する。
- クリックが増えてもゲーム開始が増えない場合は、SEOではなくページ内導線を改善する。
- 順位が安定する前にtitleや本文を毎週変更しない。変更日と理由を残し、原則2〜4週間単位で判断する。

### インデックス

- 新規ページはサイトマップへ自動追加する。
- 公開後にURL検査を行い、インデックス登録をリクエストする。
- 「クロール済み - インデックス未登録」は、再送信を繰り返さず、内容の独自性と内部リンクを見直す。

## 優先順位

### 完了

- 正規ドメイン・HTTPS・www・旧Vercel URLの統一
- robots.txt・sitemap.xml・canonical
- ブランド表記ゆれの明示
- 記事・ツールごとの固有titleとdescription
- Article / BreadcrumbList / WebApplication等の構造化データ
- ガイド・ツールのハブ
- 文章タイピング練習、速度測定、苦手キー練習、正確率計算、KPM/WPM換算、ローマ字表
- 初心者向け親ページと14日間メニュー
- ツール間・関連記事から練習ページへ進める内部リンク
- ハッシュ付き静的ファイルの長期キャッシュ
- Vercel Speed InsightsによるPC・モバイルの実測Core Web Vitals収集
- 静的なガイド・ツールページを含むVercel Web Analyticsのページ計測
- title、canonical、構造化データ、パンくず、内部リンクを検査する静的SEO監査
- IndexNow送信

### 次に判断すること

1. Search Consoleで初心者ページと既存記事の表示クエリを確認する。
2. 検索表示があるのに答え切れていない意図を、既存ページの改善で補う。
3. 文章練習ツールの表示クエリを「文章」「短文」「例文」「ローマ字」の意図別に確認し、同じ意図の薄いページは増やさず既存ページを改善する。
4. 外部掲載を再開するときは、トップだけでなく検索意図に合う解説・ツールへリンクしてもらう。

## 品質の判断基準

- 読者の悩みへの答えが冒頭にある。
- 見出しだけ読んでも行動の順番が分かる。
- 一般論の言い換えではなく、診断表・比較表・実行メニューがある。
- 著者・制作方針・更新日が確認できる。
- モバイルで読みやすく、リンク先が存在し、構造化データが妥当。
- typecheck、test、build、静的SEO監査がすべて通る。
