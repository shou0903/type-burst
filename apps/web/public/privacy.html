プライバシーポリシー

最終更新日: 2026年7月28日

TYPE BURST(以下「本サービス」といいます)における、利用者の情報の取り扱いについて説明します。

1. 収集する情報

本サービスは会員登録を必要とせず、以下の情報のみをご利用のブラウザ内(localStorage)に保存します。

  • 効果音・演出・アクセシビリティ等の設定
  • 直近10試合分のスコア・KPM・正確率などのプレイ記録
  • CPU対戦の勝敗記録
  • ランキング登録用に入力したニックネーム
  • 広告Cookieに関する同意状況(同意する/同意しない)

音量・表示・演出などの端末設定はお使いのブラウザ内にのみ保存され、ブラウザのデータを削除すると消去されます。プレイ記録のサーバー保存については、本ポリシーの「8. 匿名プレイ記録の保存と引き継ぎ」をご確認ください。

また、アクセス状況の把握のため、Vercel Web Analyticsにより閲覧ページ・参照元・国・デバイス種別等の 匿名の集計情報を取得しています(詳細は下記「3. 広告について」参照)。

世界ランキング機能をご利用いただく場合のみ、入力したニックネームと、サバイバルモードの スコア・最大連鎖・生存時間・レベルを本サービスのサーバー(Vercel上のサーバーレス関数、データ保存には Redisを利用)へ送信し、ランキング表示のために保存します。ランキングへの登録は任意であり、 ニックネームを入力しない限り送信されません。本名・メールアドレスなど、個人を特定できる情報は ニックネームに入力しないでください。

2. Cookieの使用について

本サービス自体はログイン等の目的でCookieを使用していません(上記の保存はlocalStorageのみ)。 ただし、後述の広告表示に同意いただいた場合、Google AdSenseが広告の最適化・重複表示防止等の目的で Cookieを使用することがあります。

3. 広告について

本サービスは画面の両サイドにGoogle AdSenseによる広告を表示することがあります。広告表示にはCookieが 使用されるため、初回訪問時に表示される同意バナーで「同意する」を選択いただいた場合にのみ広告(および 関連するCookie)を読み込みます。「同意しない」を選択した場合、広告は表示されません。

Googleによる広告Cookieの使用については Google広告ポリシーをご覧ください。パーソナライズ広告の無効化は Google広告設定 から行えます。

本サービスはVercel Web Analyticsを利用してアクセス状況(ページビュー・参照元・国・デバイス種別など)を 集計しています。Cookieを使用せず、個人を特定できる情報(氏名・メールアドレス・IPアドレスそのもの等)は 収集・保存されません。あくまで「どのページが・どの程度見られているか」を把握するための匿名の集計情報のみです。

4. ゲーム中に入力される内容について

本サービスはタイピング練習を目的としており、ゲーム画面に表示された定型文をローマ字で入力する形式です。 入力されたキー情報は本サービスの動作(ブロックの判定・スコア計算)にのみ使用され、外部へ送信・保存されません。

5. 第三者への提供

本サービスは利用者の情報を第三者へ販売することはありません。ランキング機能を利用した場合の ニックネーム・スコア等はランキング表示のためVercel(ホスティング・データ保存基盤)上に保存されますが、 それ以外の第三者へ提供することはありません。広告表示に同意した場合のみ、Googleが広告配信のために Cookie情報を取得します(詳細は上記「3. 広告について」参照)。

8. 匿名プレイ記録の保存と引き継ぎ

記録の引き継ぎ機能を利用した場合、当サイトはブラウザで発行する匿名のプレイヤーIDに紐づけて、ニックネーム、生涯累計、直近のプレイ結果、デイリー連続記録・フリーズ、CPU対戦戦績をサーバーに保存します。メールアドレス、パスワード、氏名その他の登録情報は収集しません。

保存の目的は、端末変更やブラウザデータ消去後にプレイ記録を復元できるようにすることです。端末固有の設定（音量、表示、演出設定など）は保存しません。記録は最後の保存から最長1年間保持し、その後削除されます。

ブラウザのデータを削除しても、既にサーバーへ保存された記録は自動では削除されません。ゲーム内の設定画面にある「クラウドに保存した記録を削除」から、保存済みの記録と引き継ぎコードを削除できます。削除後、同じコードでの復元はできません。
