タイピング練習のホームポジション
指の位置と担当キー

キーボード全体を丸暗記する必要はありません。FとJを基準点にし、各指が上下へ動く範囲を覚えます。

公開：2026年7月29日読了目安：9分初心者向け
置き方：左人差し指をF、右人差し指をJへ置きます。左手はA・S・D・F、右手はJ・K・L・;。親指はSpace付近です。別のキーを打ったら、この位置へ戻します。

ホームポジションの前後に何を練習するか迷う人は、初心者向け7ステップから自分の開始地点を選べます。

ホームポジションが必要な理由

ホームポジションは、指を置く出発点であり戻り先です。毎回同じ位置から動けば、キーを目で探さず「基準点からどの方向へ何個動くか」で入力できます。

位置がずれたまま打つと、隣のキーを押しやすくなり、どの指で打つかも毎回変わります。速さより先に、戻る動作を安定させることが重要です。

GとHは人差し指が内側へ動いて担当します。FとJには多くのキーボードで突起があるため、目を離したまま位置を確認できます。

配列やキーボード形状で記号の位置は変わります。まず日本語ローマ字で頻度の高い英字26キーを安定させ、その後に記号へ広げます。

手全体ではなく指を動かす

上段のTを打つときに左手全体を右上へ移動すると、A・S・Dの基準もずれます。手首を大きく振らず、担当指を伸ばして打った後に戻します。ただし、指が届きにくい場合に無理な姿勢を固定する必要はありません。

F・Jの突起を触り直す回数は「失敗」ではありません。正しい位置へ戻る練習そのものです。迷ったまま別のキーを探すより、一度戻る方が早く安定します。

5分の練習手順

  1. 30秒：キーボードを見て指を置き、F・Jの突起を確認。
  2. 1分：A S D F / J K L ; をゆっくり往復。
  3. 1分：Q A Z、W S Xのように縦の列を打つ。
  4. 2分：担当キーを含む短いローマ字単語を入力。
  5. 30秒：目を閉じて手を離し、F・Jへ5回戻る。

位置が崩れるときの直し方

症状原因の候補直し方
G・H付近を間違う人差し指の戻り先が曖昧FGF、JHJをゆっくり反復
上段で全体がずれる手全体を動かしているホーム段の指を残して1キーずつ
小指を使えない人差し指に頼っているQAZ、P;/だけを短時間反復
数分後に位置を失う力み・姿勢・疲労1分ごとに手を離して置き直す

手首と姿勢

肘や手首の角度には個人差がありますが、肩をすくめず、手首を強く反らせず、キーを叩きつけない状態を探します。痛みやしびれがある場合は練習を中止し、機器の高さや姿勢を見直してください。

位置がずれる瞬間を見つける

ホームポジションは「常に手を置き続ける姿勢」ではなく、迷ったときに戻れる基準です。まず10語だけ、速度を測らずに入力し、どのタイミングで位置が崩れるかを観察します。次の表で一番近い症状を選び、その行だけを直してください。

起きること確認する場所次の5分
上段を打った後、全体が右へずれる人差し指がF・Jへ戻っているかF→R→F、J→U→Jをゆっくり10往復
G・Hの境目で迷う左右の人差し指の担当を固定しているかFGF・GHG・JHJ・HJHを交互に入力
小指のキーだけ避ける手首ごと横へ動かしていないかQAZ・P;/を1組ずつ、力を抜いて反復
文章の途中で突然位置を失う先読みで指が画面より先に走っていないか2〜4文字ごとに一度だけF・Jを確認

基準位置を短文へ移す手順

  1. 1分：ASDF・JKL;を打ち、毎回同じ位置へ戻る。
  2. 2分：上下の同じ指を組み合わせる（例：frf、juj）。
  3. 2分：短い日本語を10語だけ打ち、間違えた語の前後を再入力する。
  4. 1分：手を離してからF・Jへ戻り、最初と同じ感覚か確認する。

1回の練習で残すメモ

ずれたキー例：Rの後にFへ戻れず、Tを押した
戻り方F・Jの突起／目で確認／手を一度離す
次の短語ずれたキーを含む2〜4文字を3語

迷ったときの10秒リセット

長文の途中で位置を見失ったら、焦って同じ場所を探し続けません。手を軽く浮かせ、左人差し指をF、右人差し指をJへ戻してから、直前の2〜3文字だけをゆっくり打ち直します。10秒で戻れないときは、その場の速度を下げて短い語へ切り替えます。

  1. 両手を一度キーから離す。
  2. F・Jの突起を触って左右を確認。
  3. 直前の2〜3文字を一定リズムで再入力。
  4. 同じずれが出たら、そのキーを次回の課題に記録。

始める前の30秒セット

ホームポジションの練習は、指だけを動かしても定着しません。毎回同じ向きで座り、両手が自然に置ける位置を作ってから始めます。開始前の感覚を固定すると、位置のずれと疲れによるずれを区別できます。

30秒することできた状態
10秒画面を正面にし、肩を一度下げる肘が体の横から大きく開いていない
10秒F・Jの突起を触って左右を確認手首をねじらず指がキーへ届く
10秒ASDF・JKL;をゆっくり1往復音と指の順番が一定

短語は「苦手なキーを含むが、読み方で迷わないもの」を選びます。新しいローマ字表記を覚える時間と、指の位置を練習する時間を分けると、ホームポジションの効果を確認しやすくなります。

ホーム段から文章へ進む順番

いきなり長文を打つと、ホームポジションへ戻る動作と文章を読む動作が同時になり、どこで崩れたか分かりません。文字数を少しずつ増やし、各段階で「手元を見ずに正確に通る」ことを確認してから次へ進みます。

段階素材次へ進む基準
1ASDF・JKL;と上下1キー左右の手を取り違えない
22〜4文字の短語を3つ途中で手を置き直しても続けられる
3短い日本語を10語同じキーのミスが連続しない
430秒の短文正確率を保ち、ずれを自力で戻せる

よくある質問

Bは左手と右手のどちらですか？

標準的な担当では左人差し指とされることが多いですが、配列や手の大きさで右人差し指を使う人もいます。ほかのキーが崩れず安定する方を選びます。

親指はどこへ置きますか？

Spaceキー付近へ自然に置きます。左右どちらで押すかは入力方法によりますが、手全体が崩れない側を使います。

ホームポジションを守ると遅くなります

習得初期は遅くなります。正しい戻り方が自動化されると、キーを探す停止が減るため、その後の速度を上げやすくなります。
