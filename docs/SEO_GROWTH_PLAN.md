# TYPE BURST 検索流入 5,000人／月 成長計画

更新日: 2026-07-29

## 目標と前提

最終目標は、自然検索から月5,000人が TYPE BURST を訪れる状態を作ること。
順位や流入は検索エンジンと競合状況で変わるため保証はできない。サイト側では、検索者の疑問を解決するページ、実際に使える無料ツール、クロール・計測・改善の仕組みを継続して積み上げる。

目安となる到達モデル:

- 検索表示回数: 月100,000回
- 平均クリック率: 5%
- 自然検索クリック: 月5,000回

表示回数が不足する場合は検索意図を増やし、表示は多いがクリックされない場合はタイトル・説明文を改善する。クリック後にプレイされない場合は本文と導線を改善する。

## 2026-07-29 実装済み

- 通常URLと実スクリーンショットを含む画像サイトマップをビルド時に自動生成
- canonical、JSON-LD、Article著者、OGP、h1、画像alt・寸法、内部リンク、孤立ページ、ローカルリンク切れを自動監査
- 検索対象を6ページから22ページへ拡張
- 無料ツール4本
  - タイピング速度測定
  - KPM・WPM換算
  - タイピング正確率計算
  - ローマ字入力早見表
- 高品質記事9本
  - タイピング速度の平均
  - KPM・WPMの違い
  - 正確率を上げる方法
  - ブラインドタッチ練習
  - ホームポジション
  - ミスタイプが多い原因
  - タイピング練習は毎日何分か
  - タイピングが遅い社会人の練習手順
  - KPM・WPM・正確率などタイピング結果の見方
- 記事の制作・更新方針を公開
- 制作支援ツールの利用と、人が仕様・事実・リンクを確認してから掲載する方針を公開
- 既存記事にも運営者・更新方針への導線を追加
- 全12記事に表示用パンくずとBreadcrumbListを整備
- 「左手・右手だけ苦手」「長文の後半で遅くなる」を既存の原因別記事へ統合
- 実際のプレイ画面・分析画面を関連記事へ掲載し、関連画像をサイトマップへ追加
- WebSite・Organization・WebApplication・ItemListの構造化データを整備
- プレス画像へ利用許諾を示すImageObjectライセンス情報を追加
- IndexNowへサイトマップ掲載URLを一括通知できる運用スクリプトを追加
- 記事／ツールからゲーム開始までの匿名イベント計測
- llms.txt に主要ツール・記事・運営方針を追加

## 公開直後に行うこと

1. `https://type-burst.com/sitemap.xml` がブラウザで開けることを確認する。
2. Google Search Console の「サイトマップ」で `https://type-burst.com/sitemap.xml` を送信する。
3. URL検査で次の代表ページを確認し、公開URLのテスト後にインデックス登録をリクエストする。
   - `https://type-burst.com/`
   - `https://type-burst.com/tools`
   - `https://type-burst.com/tools/typing-speed-test.html`
   - `https://type-burst.com/guides`
   - `https://type-burst.com/guides/typing-speed-average.html`
4. Bing Webmaster Tools にも同じサイトマップを送信する。
5. Search Console の検索パフォーマンスで「検索結果」「過去28日」「ページ・クエリ」を毎週記録する。

全URLへ一度に登録リクエストを連打しない。代表ページとハブを送信し、サイトマップと内部リンクからの発見を基本にする。

## 90日間の改善サイクル

### 1〜4週目: 発見と初回評価

- サイトマップの取得成功とクロール状況を確認
- 表示されたクエリを、速度・正確率・初心者・ローマ字・ゲームの5群へ分類
- 表示回数があるのにCTRが低いページを優先してタイトル改善
- 記事・ツール別の `Game Started` を確認し、プレイにつながる導線を特定
- 新規記事は増やしすぎず、まず既存ページの検索語との一致を確認

### 5〜8週目: Search Consoleの実データで拡張

次の条件を満たすクエリから記事を追加する:

- 平均掲載順位が8〜30位
- 表示回数が増えている
- 既存ページでは疑問へ十分に答えられていない
- TYPE BURSTの無料ツールまたはゲーム体験と自然に接続できる

「左手・右手だけ苦手」「長文で後半に遅くなる」は既存記事へ統合済み。「ん・っ・しゃ・じゃ・ティ」はローマ字練習記事と検索可能な早見表で回答済み。
次の新規テーマはSearch Consoleで実際に表示された未充足クエリから選ぶ。1つのクエリごとに薄いページを量産せず、同じ悩みは1つの強いページへまとめる。

### 9〜12週目: 勝ちページを伸ばす

- 4〜10位のページへ、具体例・表・無料ツール・FAQを追加
- 関連ページ同士の内部リンク文言を検索意図に合わせて改善
- 古い更新日を機械的に変えず、本文を実質更新した場合のみ `dateModified` を変更
- 外部紹介、レビュー、教育・ゲーム系メディアへの案内を行う
- プレス素材ページを売り込みメールから直接案内する

## 毎週見る指標

| 指標 | 判断 |
|---|---|
| 検索表示回数 | 検索対象と評価が広がっているか |
| 自然検索クリック | 目標5,000人に近づいているか |
| CTR | タイトルと説明文が検索意図に合うか |
| 平均掲載順位 | どのページへ追記すべきか |
| インデックス済みURL | クロール・canonical・品質に問題がないか |
| Content Entry | どの記事・ツールから本体へ来たか |
| Game Started | 検索訪問が実際のプレイへつながったか |

## 外部評価を増やす方針

- タイピング・インディーゲーム・ブラウザゲーム系メディアへ、プレス素材ページ付きで案内
- ゲーム紹介サイトへ、登録規約に従って掲載申請
- SNSでは単なるURL投稿ではなく、連鎖・分析・デイリーなど1つの特徴を短い動画や画像で説明
- 記事を紹介する場合は「KPMとWPMの換算」「正確率の診断」など、その場で役立つ内容を中心にする
- 相互リンク購入、自動生成サイトへの大量登録、検索順位保証業者は利用しない

## 品質基準

- 検索者の疑問を本文だけで解決してからゲームへ案内する
- 実際に動かないツール、未検証の数値、根拠のない平均値を載せない
- 記事ごとに固有のtitle、description、canonical、本文を用意する
- 著者、制作方針、更新日、訂正窓口を明確にする
- 誇大な上達保証や、競合サービスの誹謗をしない
- 検索エンジン向けだけの不自然な表記ゆれ反復を行わない
