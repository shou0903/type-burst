測定は「同じ条件」で比べる

タイピング速度は、文章の難しさ、測定時間、疲労、キーボードによって変わります。成長を見るときは同じツール・同じ時間で3回測り、最高値だけでなく中央値と正確率も確認してください。

結果から練習を決める簡単な基準

結果起きていること次に行うこと
速度が高く正確率が低い急ぎすぎて修正が増えている速度を5〜10％落とし、95％以上を狙う
速度が低く正確率が高い正しい指運びは作れている同じ正確率のまま短時間だけ加速する
特定の文字で止まるローマ字か指の担当が曖昧苦手キー練習で、その文字を含む10語を反復する
単語は打てるが文章で止まる先読みか後半の持続が課題文章タイピング練習で短文から長さを増やす

測った後は、ゲームで実戦練習。
